# Domain docs

Layout single-context: `CONTEXT.md` na raiz e `docs/adr/` para ADRs.

Antes de explorar, leia `CONTEXT.md` e os ADRs relevantes quando
existirem. Sua ausência não impede o trabalho; esses documentos
são criados conforme conceitos e decisões forem resolvidos.

Use o vocabulário do contexto. Registre ambiguidades e exponha
conflitos com ADRs antes de propor mudanças.

Os SDDs e `docs/DECISION_LOG.md` continuam sendo a autoridade.
Siga a ordem de leitura do `AGENTS.md` e preserve o protocolo
`ARCHITECTURE_CONFLICT`.
