# Issue tracker: GitHub

Issues e specs vivem em `dsanti-lunara/radar-de-ofertas`.
Use `gh` com `--repo dsanti-lunara/radar-de-ofertas`.

- Criar: `gh issue create --repo dsanti-lunara/radar-de-ofertas --title "..." --body-file <arquivo>`
- Ler: `gh issue view <numero> --repo dsanti-lunara/radar-de-ofertas --comments`
- Listar: `gh issue list --repo dsanti-lunara/radar-de-ofertas`
- Atualizar: `gh issue edit <numero> --repo dsanti-lunara/radar-de-ofertas`
- Comentar: `gh issue comment <numero> --repo dsanti-lunara/radar-de-ofertas --body-file <arquivo>`
- Fechar: `gh issue close <numero> --repo dsanti-lunara/radar-de-ofertas`

Preserve os IDs RDR e as referências de `docs/ISSUE_MAP.md`.
Toda issue deve seguir `docs/ISSUE_TEMPLATE.md` e `AGENTS.md`.
Publicar no tracker significa criar uma GitHub Issue.

PRs as a request surface: no.
